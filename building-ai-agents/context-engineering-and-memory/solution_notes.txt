ASSUMPTIONS

- gpt-6-luna keeps its context small on its own. Per-call input on the long
  report task never passed ~7k tokens, so the 60k default never triggers in
  normal use. The lesson has to lower --compact-at to show compaction.
- The spec's "a run that would exceed the context budget without compaction
  completes with it" could not be shown naturally for the same reason (see
  expected result). The demonstration is compaction triggering and the run
  still finishing correctly.
- Prose should say why the threshold is lowered: current models have very large
  context windows and stay compact on small tasks, so compaction only shows up
  at learning scale with a low --compact-at. In production, with long runs and
  large tool outputs, it triggers on its own. The demo is still the real model;
  only the threshold changes.
